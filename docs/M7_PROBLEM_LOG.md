# M7 evidence research — problem and negative-result log (2026-10-27)

This ledger supplements, rather than overwrites, `docs/PROBLEM_LOG.md`.

- **P-M7-001 — Search exposure is not actually READ support.** M6 unconditional bridge improved retrieval coverage but degraded a real adapter's answer EM; forced follow-up SEARCH frequently spends a call on already-visible frontier entities. **Change:** a gold-blind exact/whole-token title linkage lets the M7 policy READ an already-observed hit first, with unchanged budgets. **Evidence:** TRAIN64 27 vs 22 complete READ; open pilot32 16 vs 13; search calls smaller by 0.34375/0.375. **Residual risk:** TRAIN exposure 37 vs 38; neither difference in binary READ completion excludes zero at 95% bootstrap, and **no real model answer outcome was measured**.
- **P-M7-002 — CI fixture-missing false failure.** Initial isolated Tang scratch run had **85 passed / 10 failed / 6 errors** only because `examples/fixture/` was not copied into the isolated snapshot. No source-code error in those tests. **Resolution:** copied the read-only existing fixture into the scratch test root; **101 CPU tests passed**. After introducing the pilot hash guard and its test, **102 CPU tests passed**. GitHub Actions runs separately.
- **P-M7-003 — Arbitrary DEV32 could pass an overly weak pilot length/split guard.** Original diagnostic enforced only DEV and sample size=32; a different DEV32 subset would pass. **Resolution:** pinned BOTH opened-pilot documents and question JSONL SHA256 in the CLI; reject any different dataset before loading it. Added a failure-path unit test; known pilot32 rerun matched prior all reported metrics exactly.
- **P-M7-004 — Scripted retrieval pilot cannot establish semantic correctness.** SEARCH/READ/FINISH are genuine, but the decisions are deterministic; model-token cost, learned reasoning, answer EM, sentence-level citation completeness and entailment are **not measured**. **Resolution:** export explicit `null` for these metrics and require a matched real-model study before any default flag; do not reinterpret CPU wall-time as inference latency.
- **P-M7-005 — Statistical uncertainty is nontrivial.** Paired bootstrap 5,000 gives TRAIN complete-READ delta +0.078125 [0,0.15625], open-pilot +0.09375 [0,0.21875]; zero lies on the boundary. **Decision:** preserve as an exploratory positive read-selection signal plus a negative retrieval-exposure tradeoff, not proven task-level improvement. Do not tune to the pilot, access eval-A64 to choose query rules, or open final-B160.

## E-022/E-023 addendum — verified same day, CPU-only

- **P-M7-006 — Real model trajectory failure is dominated by lack of full retrieval, not just Verifier rejection.** Post-hoc actual **Qwen3 TRAIN-only** 12×4 rollouts vs original labelled HotpotQA sentence indices: **37/48 support_not_retrieved**, 8/48 exposed-but-not-READ, 2/48 answer wrong despite exposed sentences, 1/48 answer+sentences complete but semantics untested. Independent existing 8×4: **22/32, 8/32, 2/32, 0/32**, respectively. Complete read at only 3/48 and 2/32 vs average support READ recall ~42%. This is a descriptive earliest-gate failure hierarchy, NOT a causal intervention result. **Action:** prefer actual model second-hop retrieval and budget-aware READ experiments over unsupported claims of Verifier-given success. Source/results in `docs/M7_TRAIN_FAILURE_SENTENCE_AUDIT_20261027.md`.
- **P-M7-007 — Lexical answer mention is not entailment; cross-document token concatenation can create phantom citations.** Actual model's opened pilot32 observation-only verifier found 28/32 (both stop and bridge policies) contain answer text in some single cited READ document, but this says nothing about whether the source entails the answer; M6 separately previously reported EM6/32 stop and EM3/32 bridge. A split `new` / `york` across two cited documents can fool concatenated-source checks, and `Not Paris` contains `Paris` but should never become semantic approval. **Action:** opt-in source-only diagnostic requires lexical token sequence within ONE cited READ document; always mark semantic entailment as `not_evaluated`, and test hallucinated/duplicate citations and negations. Do not change default EvidenceAudit to an unsupported NLI label.
- **P-M7-008 — TRAIN repeated rollouts are correlated, do not resample 48 individual episodes as 48 questions.** Implemented deterministic **question-cluster bootstrap** (12 or 8 real question units, full group-of-4 episodes), fixed seed2027 and 2,000 resamples. Small-cluster uncertainty retained and intervals show no robust complete-read or answer+sentence success. Original TRAIN `original_train_subset.json` found and SHA pinned; labels consumed **only** by offline audit after each actual SearchAgent rollout. Tested **111 CPU tests** + green GitHub Actions at source SHA `6185e55051ac25e353623355633c1d0122d7bd6c`.
- **P-M7-009 — BM25 stopwords silently erased wh interrogatives needed for query-rewrite relation extraction.** A pre-data unit test expected `Congress of Vienna austrian statesman` but got `Congress of Vienna chaired austrian statesman`; root cause `retrieval.tokenize(question)` strips `what` before tail segmentation. **Resolution:** parse raw lowercase question words to find the last wh-question word, then filter irrelevant suffix tokens. Fixed `c5546f33e97d6bea963a5c97678f07050c7d3add`.
- **P-M7-010 — Untrusted evaluator event could change future plan despite no direct gold read.** Injecting an `eval_only` observation after real READ caused relation-tail branch to skip rewriting based on `observations[-1].kind`, potentially leaking evaluator metadata into action timing. **Resolution:** explicitly filter to allowed SEARCH/READ observation kinds before *all* relation planning and fallback delegation. Fixed `a5e1777e537fd9d616576186a49ec8cca6a64568`; unit tests cover gold perturbation. Subsequent **116/116 Tang CPU tests passed**, original two failures reproduced and resolved. No live policy or hidden eval labels involved.
- **P-M7-011 — TRAIN-only question-tail rewrite does NOT generalize on the opened pilot32.** Pre-registered two disjoint TRAIN64 cohorts improved complete READ **27→30** each under unchanged budget, but independent frozen open pilot32 saw *worse* complete retrieval **22→20**, **equal** complete READ **16→16**, and **slightly higher** tool calls 3.59375→3.625. All binary bootstrap CIs touch zero; no actual LLM answer/semantic result. **Decision: REJECT** rewrite promotion; preserve the fixed negative pilot and do **not** tune it further on pilot or access eval-A64/final-B160. Report and immutable raw run paths in `docs/M7_E023_RELATION_TAIL_REWRITE_ABLATION.md`.

**Boundaries:** These are actual CPU code/test/trajectory-audit/retrieval experiments on the M7 evidence branch, *not* model updates or proof of better Qwen3 QA. Tang GPU was in use by another training stream and was neither commandeered nor interrupted.


## E-025/E-026/E-027 semantic-reliability addendum — CPU verified, 2026-10-27

- **P-M7-012 — Citation leave-one-out is only a MODEL-sensitivity test.** E-025 showed a genuinely incorrect Qwen3 answer (1962) could still appear NLI-necessary for both cited READ sources. Two confident model-necessity passes out of eight candidates included **one wrong answer**. **Decision:** LOCO remains an opt-in falsification diagnostic, NOT a reliable semantic truth oracle or default Verifier. See `docs/M7_E025_COUNTERFACTUAL_NLI_AUDIT_20261027.md`.
- **P-M7-013 — E-026 controlled TRAIN test falsifies strong NLI approval reliability for unsupported links.** Cached CPU mDeBERTa MNLI evaluated **36 real original TRAIN supporting-sentence contrasts / 12 independent question clusters**. Three-way editorial-label agreement **32/36**, yet **2/12 editorial neutral near-misses confidently mislabeled as entailment** (Jill Duggar show attribution p=.99483; FA Community Shield → FA Cup competition conflation p=.94061). No independent human adjudication; these are valid diagnostic concerns, not authoritative semantic ground truth. Original explicit negations 12/12 predicted contradiction, which is not evidence of low unsupported-bridge FPR. **Decision:** reject raw p-entail threshold 0.85 as a truth certificate.
- **P-M7-014 — E-027 ablation works for clean exact-hypothesis evidence deletion but not relationship near-misses.** Ten same-hypothesis official-source-removal pairs; **9/10** satisfy pre-fixed E-025 necessity gate, mean entailment drop **0.945874** (question-cluster CI **[0.885858,0.981572]**). Still the two unsupported near-misses pass a high-confident single-premise NLI prediction. **Decision:** source necessity does not imply factual correctness; no Verifier promotion, pilot repetition or eval-A64 access.
- **P-M7-015 — Evaluation code mishandled zero eligible ablation pairs.** First E-027 CPU run **153 passed / 1 failed**: helper divided by zero / raised instead of recording a zero-denominator estimate. **Fix:** return explicit `null` rate and CI with `reason=no_eligible_paired_cases`, not 0% or guessed success. Also removed a misleading field that could conflate loss of evidence support with change in external proposition truth. **Final:** **154 CPU tests passed** at source SHA `650d595910db41e1af83d89033fdf8e1bf0b2895`; immutable E-026/E-027 CPU output SHA256 values and exact reproduction commands in `docs/M7_E026_E027_SEMANTIC_CONTRAST_ABLATION_20261027.md`.

**Open research gap:** neither the 36-case editorial contrast suite nor the 80-episode prior live-model retrospective NLI audit is an **independently human-adjudicated semantic entailment benchmark**, and neither by itself measures a new online Qwen3 QA improvement. Next freeze independent disjoint TRAIN semantic judgements; measure false approval/rejection against those labels. Do not use DEV gold to calibrate thresholds; no eval-A64 or final-B160 until a prospective frozen-policy gate is justified.
