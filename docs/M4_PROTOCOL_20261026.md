# M4 pre-registered evaluation protocol (2026-10-26)

## Aim
Determine whether gold-blind citation/tool guards yield **more correct AND passage-supported multi-hop answers** than a plain Qwen3-8B-AWQ Search Agent, with honest model-call/token/latency cost. This is a baseline-plus-ablation evaluation before any model-weight update; not RSI.

## Data and leakage contract
- Original HotpotQA distractor **dev**, 7,405 total, file SHA-256 `4e9ecb5c8d3b719f624d66b60f8d56bf227f03914f5f0753d6fa1b359d7104ea`.
- Freeze **256** question IDs independently of answers by sorting SHA256(`42:<question_id>`).
- **Pilot 32:** first 32 hash-ranked. Contains all prior diagnostic 24. Used for parameter/strategy selection.
- **Heldout 224:** remaining 224 hash-ranked; disjoint from pilot. Divide into **eval-A first 64** (single-vs-guard generalization check) and **sealed final-B remaining 160** (do NOT evaluate, inspect labels for tuning, or use for SFT until a pre-registered training comparison is ready).
- All these examples originate in official **dev**, not official hidden test or full-Wikipedia. One question searches only the supplied distractor passages.
- Separate HotpotQA **TRAIN** must be used for SFT/GRPO. Never train using any dev pilot/heldout answer, supporting sentence, or trace labelled by gold.

## Existing pilot32 observations (real GPU Qwen3-8B-AWQ)

| Condition | Model config | EM | Strict verified | Evidence recall | Model calls | Latency |
| --- | --- | --- | --- | --- | --- | --- |
| B0 baseline | Unboosted BM25, vanilla OpenAI-compatible policy | 7/32 | 0/32 | 0.375 | 3.8125 | 2.299 s |
| R1 retrieval-only | Title-boost=0.25, vanilla policy | 7/32 | 0/32 | 0.4375 | 3.8125 | 2.317 s |
| G1 evidence guard | Title-boost=0, min_reads=2, one bounded citation revision | **10/32** | **4/32** | 0.609375 | 4.90625 | 3.504 s |
| R1+G1 | Title-boost=0.25, same guard | 9/32 | 4/32 | 0.625 | 4.84375 | 3.661 s |

Pilot-only BM25 question-query Top3 full support went from 14/32 (unboosted) to 17/32 (boost=0.25); this **did not independently improve end-to-end EM**. A 6-candidate boost sweep found best top3 coefficient 0.25 using pilot labels. No heldout labels used.

**Fixed selection for next eval-A:** B0 vs **G1** (without title boost), because G1 has pilot-best strict verified success (tied with R1+G1), better EM and latency within that tie. Do NOT change parameters after reading eval-A results.

## Both eval-A runs have equal tool allowances
- Same frozen first 64 of heldout QA, same model Qwen3-8B-AWQ, vLLM0.31.0 local endpoint, `enable_thinking=False`, greedy temp0, strict bounded action oneOf JSON schema, `max_steps=6`, `max_tool_calls=5`, `search_top_k=3`, `title_boost=0`, same document read limit, seed42.
- Only policy differs: `openai` vs `grounded-openai --min-evidence-reads 2` with one optional evidence-grounded revision. All extra model inference calls and tool actions are counted and reported.
- Code for both must use exact SHA **`5e8e6b6a671cc39e2a817e3bbc6b687d541ae666`** and source manifest.
- Primary metric: strict verified success = normalized answer exact AND all gold-support passages cited AND answer literal in cited passage text; secondary: answer EM, F1, cited evidence recall, termination errors. Note the verifier checks **passage title-level** supporting evidence, not original sentence-level entailment.
- Cost: wall-time per question, total model calls, input/output tokens, search/read calls. Aggregate paired per-QA results and Wilson/paired bootstrap confidence intervals. Zero verified gain or negative results remain published.
- Never claim repeated prompt guard is a separate fine-tuned model, RL or RSI. Need actual weights updated and external evaluation for that.
